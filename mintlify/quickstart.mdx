Sisera is organized as a **pnpm / Turborepo TypeScript monorepo**. You can boot the full terminal locally with zero external identity keys using Local Operator Mode, or connect live Solana RPC, Pyth, Jupiter, Clawpump, and Privy credentials for full production parity.

---

## Prerequisites

- **Node.js:** `v20+` (recommended `v22` or `v24`)
- **Package Manager:** `pnpm` (`v9+`)
- **Database:** PostgreSQL `15+` (for accounts, append-only ledger, policies, agents, launches,marketplace, and corroborated events)

---

## 4-Step Local Boot

<Steps>
  <Step title="Clone the Repository & Copy Environment Config">
    ```bash
    git clone https://github.com/hackcat29/Sisera.git
    cd Sisera
    cp -n .env.example .env
    ```
  </Step>
  <Step title="Install Monorepo Dependencies">
    ```bash
    pnpm install
    ```
  </Step>
  <Step title="Run PostgreSQL Schema Migrations">
    Ensure `DATABASE_URL` in `.env` points to a running PostgreSQL instance, then apply all sequential migrations:
    ```bash
    pnpm db:migrate
    ```
  </Step>
  <Step title="Start the Terminal & Control Plane">
    ```bash
    pnpm dev
    ```
    - **Web Terminal (`apps/web`):** [http://localhost:3000](http://localhost:3000)
    - **API Control Plane (`apps/api`):** [http://localhost:4000](http://localhost:4000)
  </Step>
</Steps>

<Tip>
  By default, `pnpm dev` loads `.env`, preserves your custom keys, and enables **Local Operator Mode** (`SISERA_LOCAL_OPERATOR_MODE=true`), allowing you to explore the entire terminal without configuring Privy authentication first.
</Tip>

## Environment Variables Reference

All server-side credentials remain strictly inside `apps/api` and are never exposed to the browser bundle.

<AccordionGroup>
  <Accordion title="Core Database & Identity (PostgreSQL & Privy)" icon="database">
    | Variable | Description |
    | --- | --- |
    | `DATABASE_URL` | PostgreSQL connection string for accounts, ledger, policies, agents, launches, and events. |
    | `NEXT_PUBLIC_PRIVY_APP_ID` | Public Privy Application ID used by `apps/web`. |
    | `PRIVY_APP_ID` | Server-side Privy Application ID (must match `NEXT_PUBLIC_PRIVY_APP_ID`). |
    | `PRIVY_APP_SECRET` | Server-side Privy verification secret for validating bearer tokens. |
    | `SISERA_LOCAL_OPERATOR_MODE` | Set `false` in staging/production to require real Privy authentication. |
    | `SISERA_ALLOW_DEV_AUTH` | Set `false` in staging/production to reject local developer headers. |
  </Accordion>

  <Accordion title="Solana RPC, Pyth Core, Jupiter & Clawpump" icon="coins">
    | Variable | Description |
    | --- | --- |
    | `HELIUS_API_KEY` | Helius API key for wallet balances, DAS token holdings, enhanced history, and holder concentration. |
    | `SOLANA_RPC_URL` | Primary Solana mainnet RPC endpoint for DBC simulation, token launches, and USDC settlement. |
    | `JUPITER_API_KEY` | Authenticated Jupiter API key for live Solana swap quotes, routing, and prediction markets. |
    | `PYTH_API_KEY` | Authenticated Pyth Pro / Core API key for real-time equity reference feeds. |
    | `PYTH_HERMES_URL` | Pyth Hermes endpoint URL for streaming and polling equity price feeds. |
    | `CLAWPUMP_API_KEY` | Partner API key for Clawpump token discovery, stock-paired quotes, and self-funded agent launches. |
    | `SISERA_DBC_PARTNER_WALLET` | Optional Solana recipient wallet for Meteora Dynamic Bonding Curve partner fees. |
  </Accordion>

  <Accordion title="Intelligence, SEC EDGAR & AI Narration" icon="brain-circuit">
    | Variable | Description |
    | --- | --- |
    | `OPENROUTER_API_KEY` | API key for LLM narration in Sisera AI and structured stock research assessments. |
    | `SISERA_INTELLIGENCE_MODEL` | Model identifier used for intelligence summarization and policy drafting. |
    | `SEC_EDGAR_USER_AGENT` | Mandatory contact header required by SEC EDGAR (e.g., `Sisera research@sisera.xyz`). |
    | `MARKETAUX_API_KEY` | Financial news ingestion and entity sentiment provider key. |
    | `GNEWS_API_KEY` | Global news search provider key. |
    | `FINNHUB_API_KEY` | Company news, earnings, and institutional market data key. |
    | `COINMARKETCAP_API_KEY` | Broad crypto market breadth and reference metadata key. |
  </Accordion>

  <Accordion title="Live Execution & Feature Flags" icon="sliders">
    | Variable | Description |
    | --- | --- |
    | `SISERA_LIVE_SOLANA_ENABLED` | Master toggle (`true`/`false`) for live Solana token and equity swaps. |
    | `SISERA_LIVE_PREDICTIONS_ENABLED` | Master toggle (`true`/`false`) for live Jupiter prediction market orders. |
    | `SISERA_LIVE_BINANCE_ENABLED` | Master toggle (`true`/`false`) for live Binance spot execution. |
    | `SISERA_LIVE_LAUNCHES_ENABLED` | Master toggle (`true`/`false`) for live Clawpump and Meteora DBC launches. |
    | `SISERA_LIVE_AGENTS_ENABLED` | Master toggle (`true`/`false`) for `limited_live` and `live` agent lifecycle stages. |
    | `SISERA_DELEGATED_SIGNING_ENABLED` | Enables automated live execution for wallets with delegated Privy session signers. |
    | `PRIVY_AUTHORIZATION_PRIVATE_KEY` | Private key authorizing server-side delegated Privy session signing within risk mandates. |
    | `SISERA_SCHEDULER_ENABLED` | Controls background policy (30s), agent (60s), wallet leaderboard (30s), and event (15m) loops. |
  </Accordion>
</AccordionGroup>

## Verification & Testing Suite

Before pushing changes or deploying to production, run the full verification pipeline from the repository root:

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

To run targeted integration tests for specific subsystems:

<CodeGroup>
```bash Platform & Clawpump Tests
pnpm --filter @sisera/api test -- test/platform.test.ts
```

```bash Stock & Pyth Integrations
pnpm --filter @sisera/api test -- test/stock-integrations.test.ts
```

```bash Marketplace & Wallet Leaderboard
pnpm --filter @sisera/api test -- test/marketplace.test.ts
```
</CodeGroup>
